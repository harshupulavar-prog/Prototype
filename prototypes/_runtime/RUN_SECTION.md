## How to run

**Requirements:** Python 3.9+ and Node.js 18+.

**Automatic:** open this folder in VS Code and click **Yes / Allow** when asked to trust the folder and allow automatic tasks. The app installs itself and starts, and your browser opens.

**Manual (any terminal):**
```bash
python run.py        # use python3 on macOS / Linux
```
Press `Ctrl+C` to stop.

If VS Code did not start it, press `Ctrl+Shift+B` and choose **Run prototype**.
